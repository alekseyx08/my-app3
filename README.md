# my_app3

Лабораторная работа №4 — «Управление состояниями» (Cubit).  
Мобильное приложение на Flutter, демонстрирующее работу с управлением состоянием через `flutter_bloc` и `Cubit`.

## Стек технологий

- Flutter (SDK 3.5.0+)
- Dart
- flutter_bloc: ^8.1.6
- bloc: ^8.1.4
- Cupertino Icons: ^1.0.8

## Цель работы

Получить понимание управления состояниями и научиться управлять состояниями мобильного приложения. В проекте реализован подход на базе Cubit (подмножество BLoC), без событий — только состояния и методы изменения состояния.
